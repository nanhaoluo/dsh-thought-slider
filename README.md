# dsh-thought-slider

DeepSeek Harness 思考强度滑块的独立视觉增强插件，提供 ZCode / Codex 风格的胶囊轨道、白色旋钮和最高档粒子效果。

## 使用前提

本插件增强现有 `.bre-effort-slider` 滑块（包括 [dsh-better-reasoning-effort](https://github.com/HaoyueQin/dsh-better-reasoning-effort) 的对应结构），**不会独立创建滑块或增加模型的思考档位**。需要在同一个 DSH Web profile 中安装并启用该插件的滑块功能，且当前模型至少配置两个思考档位。

兼容的 DOM 结构：

- 当前 `dsh-better-reasoning-effort` 0.5.4：`.bre-effort-track`、`.bre-effort-knob`、`.bre-effort-input`，从宿主的 `--bre-progress` 读取预览进度。
- 旧结构：`.bre-effort-slider-fill`、`.bre-effort-slider-thumb`，从宿主旋钮的百分比位置读取进度（外观兼容；意图吸附需要明确的 range 定义，或 role=slider 的 aria-valuemin/max 离散档位定义）。

上游若改变这些结构，需要重新核对兼容性。遇到未知结构或无有效进度时，插件保留宿主原样。

## 本地安装

在本项目目录运行：

```sh
npm run build
# 尚未安装滑块提供方时执行：
dsh plugin --profile web add dsh-better-reasoning-effort
# 将本地修复版安装到同一个 profile：
dsh plugin --profile web add .
```

安装完成后重启该 DSH profile 并刷新 Web 页面。其他 profile 请替换命令中的 `web`。插件的安装和重启边界见 [DSH CLI 官方说明](https://github.com/deepseek-ai/deepseek-harness/blob/master/apps/cli/reference/README.md)。

移除本增强插件：

```sh
dsh plugin --profile web remove dsh-thought-slider
```

## 视觉与交互

- 24px 胶囊轨道、两侧 14px 间距、28px 正圆白色旋钮；旋钮中心对齐轨道端点，两侧各预留 14px，右端轨道盖在旋钮下方。
- 填充随位置从青蓝连续过渡到蓝紫，最高档叠加蓝紫色流光；填充和旋钮使用同一进度，与宿主点击坐标保持一致。
- 最高档运行 20 个粒子，单程 2.0–3.6 秒。每颗独立随机高度、速度、大小和透明度；约 80% 越过左侧裁切边缘后销毁，约 20% 提前淡出。生命周期结束只替换该粒子，不触发全页扫描；减少动态效果时暂停。
- 保留模型配置的档位名称、键盘操作、禁用状态及提交/回滚逻辑；拖动连续跟随指针，松手按配置档位进行意图吸附。有旧版中文标题时，将“思考等级”显示为“思考强度”。
- 保留宿主模型菜单的布局、颜色、模型列表和原有档位标签；外观修改只作用于滑块及其标题。

## 修复内容

- 支持当前宿主的实际 DOM，解决旋钮/填充选择器失配导致增强不生效。
- 不再把宿主的百分比位置改写成 `calc()`，避免再次扫描时误判为 50%，以及视觉位置偏离拖动坐标。
- 样式和输入更新仅刷新受影响的滑块；拖动预览在当前事件中立即绘制，仅结构变化才按动画帧扫描，避免全页查询、额外一帧延迟及观察器自触发循环。
- 气泡横向容器使用有效的 `left` / `right` 定位，覆盖整条填充轨道。
- 卸载时取消待执行扫描、移除粒子与样式，恢复标题和插件自己的属性，同时保留宿主更新后的档位。

本插件通过 `dsh.profile.bundles` 挂载，不修改第三方 npm 插件源码。增强层负责显示与指针吸附，通过原宿主指针事件交回宿主，不直接发送模型选择请求，也不额外注册快捷键。MTL 模型菜单支持拖动时合并并同步最新档位；普通 range 宿主仍保留松手提交协议。

## 1.0.3 精简外观

按实际模型菜单截图收敛为“思考强度 / 当前档位”、渐变轨道、白色正圆旋钮，以及宿主原有的 Off / Low / High / Max 等档位标签。移除 1.0.2 新增的“更轻量 / 更深入”说明和额外圆点，不再覆盖整个模型菜单的边框、阴影、提供商宽度或模型行样式。

已有标题和档位标签的菜单直接沿用宿主内容；没有标题的独立 range 控件仅补一行标题和当前档位（来自 `aria-valuetext`），不硬编码模型档位名称或数量。保留端点遮挡、最高档粒子与三信号吸附，卸载时移除插件自己的节点。

## 1.0.1 意图吸附

仅在模型明确配置的离散档位停靠，精确落在档位时直接保持；落在两档之间时，计算选择较高档位的加权分数：

- 落点距离权重 **55%**：越接近高档，分数越高。
- 起点到落点的整体位移权重 **30%**：向右倾向高档，向左倾向低档；位移按一个档位间距归一化并限幅。
- 最近移动矢量权重 **15%**：采用衰减累计和平滑，过滤亚像素抖动，避免最后一点反向扰动推翻整体意图。

分数达到 0.5 选择高档，否则选择低档。无移动的单击选择最近档位；拖动过程的位置连续跟随，标题预览对应档位，仅松手时吸附。模型档位数来自 range 的 min/max/step，不固定为四档或五档；无有效离散定义时保留宿主输入。

响应优化包括：同档位内的连续移动不重复通知宿主，预览无需等待网络响应，只有松手才调用宿主原来的提交过程；请求被拒或拖动取消时仍由宿主恢复原档位。

## 1.0.5 实机兼容

修复宿主 `corner-shape: superellipse(1.5)` 把 50% 圆角画成圆角方形的问题；旋钮显式使用普通圆角，轨道同时固定 24px 的高度与最小/最大高度，避免宿主 30px 最小高度撑粗轨道。所有新增行内样式在卸载时恢复。

支持实际 dsh-model-think-level 2.3.3 的 ARIA 滑块。拖动直接同步绘制预览，松手才通过宿主原来的指针处理器提交一次；取消拖动不会调用该宿主的“取消即提交”处理器。现代 range 结构仍沿用原来的预览事件协议。增强层私下使用原生观察器，避免其他插件的 150ms 包装延迟，不改变页面全局构造器。

新增实际安装版 MTL 组件与样式测试夹具，目录/排序服务和后端为测试桩；另在真实 Electron 界面核对尺寸、普通圆角及指针渲染。


模型菜单兼容修复：仅在包含本插件滑块的菜单内解除其他样式的 360px 高度上限，保留完整的标题与档位标签；窗口空间不足时缩小并滚动模型列表。菜单尺寸变化时只通知宿主重新定位，不自行重写弹窗坐标。


粒子位于独立 Shadow DOM 内；生命周期的节点替换不会穿透给全页 MutationObserver，避免触发模型设置兼容插件的延时全页巡检。菜单重新定位会等待拖动结束，避免 resize 监听器取消当前手势。

仅当 MTL 的完整模型选择器与增强滑块同时在位时，兼容层阻止其他插件重新显示宿主根层的重复菜单单元；模型列表中的选项保持可见。


## 1.0.6 连续拖动与配色

旋钮和填充在拖动中连续跟随指针；标题按移动意图显示对应档位，松手再用原有三信号权重确定最终档位，并在 120ms 内吸附。抓住旋钮边缘时保留抓取偏移，避免按下即跳位。单击轨道即时选择最近档位，独立等待宿主确认，防止提交前闪回旧位置；慢请求仍由宿主确认或回滚。

普通档位采用随位置连续变化的青蓝到蓝紫渐变；最高档使用蓝紫光斑流光，以随机的二维路径、缩放和明暗变化移动；每段结束重新生成路径，并保留接点避免跳变，遵循减少动态效果设置。轨道和旋钮尺寸仍为 24px / 28px，粒子仍为 20 个及原定中等速度。


MTL 保存请求未完成时仍可继续拖动或点击。增强层保留最后一次意图，宿主解锁后自动补交，合并过时的中间操作；切换模型或卸载时取消旧队列。普通禁用的 range 输入仍尊重宿主禁用状态。


## 1.0.7 缓慢极光

最高档使用更宽、更柔和的蓝紫极光带。每段随机路径持续 18–30 秒，以较小位移、缩放和亮度变化缓慢舒展；相邻路径保持接点连续，避免闪烁。白色粒子及连续拖动、快速操作队列保持原有设定。

## 1.0.8 连续调节与实时同步

修复外层禁用样式阻断命中、其他插件接管指针捕获或漏掉松手事件后无法继续拖动的问题。拖动事件由窗口捕获阶段兜底，新手势会清理遗留状态；保存过程中继续保留最新意图，解锁后串行提交，避免并发请求覆盖。

MTL 菜单拖动时，标题和配色立即显示意图档位；档位稳定约 80ms 后通过宿主原处理器同步保存，无需等松手。忙时合并为最后一个目标，松手确保最终目标送达。网络确认仍取决于宿主响应，失败仍由宿主回滚。普通 range 宿主保持原来的松手提交。

最高档样式按当前意图档位启用，与标题一致，无需把旋钮拖到 100%。点击和松手吸附使用 180ms 缓动，按住拖动保持直接跟手。普通轨道的色相随实际拖动位置连续变化，点击时通过可插值色相与旋钮同步过渡，避免跨档跳色。最高档效果在进入和退出时淡入淡出，并轻微缩放、柔化；退出动画期间继续移动，淡出后再暂停。

蓝紫光带固定为三条独立流光，初始生命周期错开并加入随机偏移，避免同步出现和消失。每条生成时随机确定留存时间、方向、速度和形状，在 10–16 秒生命周期内沿固定方向匀速移动，独立淡入和淡出；结束后销毁并生成新的流光。扩大移动范围，流光在途中保持方向和速度，减少来回摆动。轨道、旋钮及白色粒子的尺寸和数量保持原有设定。

回归验证覆盖连续 12 次反向切换、保存中继续拖动、按住实时保存、指针捕获被接管、不同指针的遗留手势恢复、最高档提前启用和点击/吸附缓动；本地目录测试桩之外，另在目标 Electron profile 中验证真实保存结果。

## 1.0.9 轻微弹簧回弹

点击切换和松手吸附改为带阻尼的弹簧曲线：从静止平顺加速，接近目标后轻微越过并自然收稳，只保留一次约移动距离 1.5% 的回弹。动画按实际移动距离在 240–400ms 内调整，短距离吸附更利落，跨档切换更舒展；填充与旋钮使用相同运动曲线，色相独立平滑过渡。

按住拖动仍直接跟随指针，重新抓住移动中的旋钮会立即中断动画。回弹只影响显示，提交的仍是准确档位，不会额外发送模型设置请求。减少动态效果时直接到位。
